# Bagages Tala Ouglid

Site statique (GitHub Pages) + Supabase pour recevoir commandes et messages.

1. Supabase : nouveau projet, SQL Editor, exécuter `setup.sql`.
2. Authentication > Users : créer votre compte (e-mail + mot de passe). Authentication > Sign In / Providers : désactiver « Allow new users to sign up ».
3. Project Settings > API : copier l'URL et la clé `anon` dans `config.js`.
4. Publier sur GitHub Pages ; vos commandes, messages et colis sont dans `/admin.html`.
